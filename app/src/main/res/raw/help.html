Adding a reminder

Reminders are added via the "Add reminder" dialog, which can be reached in the following ways:

  • Click on the launcher icon "Add reminder"
  • Long-click on the launcher icon "Ding" and select "Add reminder"
  • Use the Quick Settings tile (has to be first added by clicking the "edit" symbol in the Quick Settings menu)
  • Click the "+" button in the reminders list

Selecting time and date via widgets

Select a time using the clock widget and enter a message. Initially, the selected time refers to the next occurrence of the hour/minute within the next 24 hours. If this is on the next day, this is indicated with a blue "+1" next to the displayed date. To select a date more than 24 hours ahead, use the +/- buttons or click on the date. The "+x" next to the date indicates how many days the selected date is ahead. The date is displayed in orange to indicate that it is chosen manually.

Specifying time via text

This feature can be enabled in the settings.

As an alternative to using the clock widget, the reminder time can be specified via text by typing it at the beginning of the text field. The dot separates hours from minutes in a clock time, and the colon in a time counted from now. The available formats are (where [x] represents an optional part):

  • h[h].mm – the clock time, 24 hour format, hours 0 to 23 and minutes 00 to 59. "12.30" means half past twelve, "9.05" five past nine.
  • +h[h][h]:mm – that many hours and minutes from now. "+1:30" means in one hour and thirty minutes.
  • h[h][h]:mm – the same as above without the plus, so it is also counted from now. "12:30" means in twelve hours and thirty minutes, not half past twelve.
  • +m[m][m] – that many minutes from now. "+90" means in ninety minutes.
  • :m[m][m] – the same as above without the plus. ":90" also means in ninety minutes.

The minutes are always two digits when hours are given, so "1:2" and "12.3" are not recognised as a time.

A space separates the time specification and reminder text.

If the date is changed through an addition of hours and minutes, this is diplayed with a green "+x" next to the date.

It is possible to combine setting date and time with widgets and text. For example, one can select the date with buttons or the calendar, and independently specify the clock time via the "hh.mm" format. However, a time counted from now (any of the colon formats, with or without the plus) sets the date as well and will always reset any previous choices. Using the clock widget removes any text-based time specification, which is a useful way to correct the selected time.

Adding the reminder

To add the reminder, either click the "Add" button on the keyboard (usually a button on the bottom right, with a symbol or titled "Add") or click "Add" at the bottom of the dialog.

After adding a reminder, the time until it is due is shown in hours and minutes (additional seconds are not displayed). If the reminder is at least 24 hours ahead, the number of (calendar) days and hours is shown (minutes are not shown and rounded towards the closest hour).

Nagging reminders

The switch next to the reminder text makes the reminder "nagging": when due, the notification will be renewed every x minutes, producing the same alert (sound, vibration, ...) as when first shown. This continues until the notification is dismissed.

The repeat interval for the current reminder can be adjusted by long-clicking the switch; it is between 1 minute and 1440 minutes (24 hours). The default value can be changed in the settings.

Currently there is no indication in the reminders list or the notification whether a reminder is nagging, this will be added later.

Editing a reminder

To edit a reminder, either click on the notification or the entry in the reminders list.

Marking a reminder done

Swipe the notification away, or long-click the reminder in the reminders list and choose "Mark done". Clicking the notification opens the reminder for editing instead; the notification has no button for marking it done.

Reminders list

The reminders list can be reached via

  • The launcher icon "Ding"
  • Long-clicking on the "Add reminder" launcher icon and selecting "Show reminders"
  • Long-clicking on the Quick Settings tile

The reminders list shows all current and past reminders and allows to edit or reschedule them. In addition reminders can be marked as done or deleted. Long-click on a reminder to select it (and potentially further reminders) and see the available actions (a long click on an action symbol shows its name).

The list consists of three sections:

  • Due reminders (yellow): Reminders due according to the set time; a notification has been shown and the reminder has not been marked as done yet (e.g. by dismissing the notification)
  • Scheduled reminders (green): Reminders with due date in the future, a notification will be shown when the due time is reached; this section is further divided into days for the next 7 days
  • Done reminders (grey): Reminders for which the notification has been dismissed or which have been marked done manually

Do Not Disturb mode

By default, reminders should not be shown in Do Not Disturb mode (however, the notification can be seen as soon as Do Not Disturb is disabled). This behaviour can be changed in the system settings under Notifications -> Do Not Disturb -> Alarms and other interruptions. If you enable the category "Reminders", normal and nagging reminders will be shown even in Do Not Disturb mode, with sound and vibration as configured.

Configuration

Reminder dialog size

If the "Add reminder" dialog is too large or too small for your preferences, sizes of the clock widget and the time display can be changed under Settings -> Reminder dialog settings. This can for instance be useful on small screens or with high keyboards, where too much of the dialog is hidden by the keyboard (even though in many cases it is still possible to use the dialog this way, for example by adding the reminder with the "Add" button on the keyboard).

Tips

  • To test how a reminder is shown, set the time one or two minutes ahead and add the reminder. A reminder has to be due in the future: adding one for the current minute is refused with "Invalid date: must be in the future".
