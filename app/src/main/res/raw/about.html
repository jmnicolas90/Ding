Known problems

On some devices, especially older, it can happen that a reminder is shown a few minutes late, or that reminders scheduled for the next day or later are not shown at all. Please test for yourself and report it if you experience this!

Feedback

Github issues are the only contact channel for this project. If you discover a problem or have a suggestion, please open an issue on Github.

Contributing

In addition to giving feedback, you are also welcome to implement features or help with graphics design. See Contributing.
